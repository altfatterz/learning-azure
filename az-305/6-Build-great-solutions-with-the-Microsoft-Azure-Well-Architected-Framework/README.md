# Build great solutions with the Microsoft Azure Well-Architected Framework

## Introduction to the Microsoft Azure Well-Architected Framework

- `Azure Well-Architected Framework pillars`

## Microsoft Azure Well-Architected Framework - Reliability

- When you need it, `does what it's supposed to do`, and `doesn't unexpectedly break down`.

- Design for `business requirements`
- Design for `resilience`
- Design for `recovery`
- Design for `operations`
- `Keep it simple`

## Microsoft Azure Well-Architected Framework - Security

- Plan your `security readiness`
- Design to `protect confidentiality`
- Design to `protect integrity`
- Design to `protect availability`
- Sustain and `evolve your security posture`

## Microsoft Azure Well-Architected Framework - Cost Optimization

- `Cost Optimization`
  - unlike `cost-cutting` (laying off staff or cutting budget caps) - cost optimization is `strategic, ongoing discipline`
  - just to spend less, but to get the `highest possible business value out of every dollar spent`.

- Develop `cost-management discipline`
- Design with a `cost-efficiency mindset`
- Design for `usage optimization`
- Design for `rate optimization`
- `Monitor and optimize over time`

## Microsoft Azure Well-Architected Framework - Operational Excellence

- `Operational Excellence`
  - Are we building an `entire system` and `culture` where:
    - problems are fixed automatically
    - value flows seamlessly to the customer
    - performance gets better every single day
  
- Embrace `DevOps culture`
- Establish `development standards`
- Evolve `operations with observability`
- `Automate for efficiency`
- Adopt `safe deployment practices`

## Microsoft Azure Well-Architected Framework - Performance Efficiency

- `Performance efficiency` - getting the absolute most output or value out of a system while using the fewest resources possible. 

- Negotiate realistic performance targets
- Design to `meet capacity requirements`
- Achieve and `sustain performance`
- Improve efficiency through optimization
